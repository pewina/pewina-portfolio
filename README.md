# Pewina Francy — Portfolio

A responsive React + TypeScript portfolio built with Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Visual direction

The homepage takes inspiration from an expressive, oversized editorial landing page while keeping the portfolio's warm, elegant identity. It includes:

- A large typographic name treatment with soft cloud-like gradients and decorative orbits.
- A floating responsive navigation with active-section highlighting.
- Clickable focus chips that switch the hero introduction between AI & Data Science, Web Development, and Creative UI/UX.
- Motion-enhanced calls to action and a featured SilverHands AI preview card.
- Reduced-motion support and responsive mobile navigation.

The updated palette uses ivory, warm cream, deep wine, rosewood, dusty rose, and champagne. Charcoal has been replaced with a softer rose-ink tone across the site.

## Featured projects

- **SilverHands AI** — AI-powered livelihood and opportunity matching platform.
- **NeuroLimb AI** — self-healing neural-network simulator for smart prosthetic limb control.
- **Credit Card Fraud Detection** — Logistic Regression and Isolation Forest on a highly imbalanced transaction dataset.
- **LearnBridge AI** — inclusive learning and student-support app with accessibility controls, mood check-ins, and child-safety guidance.

LearnBridge AI is included as a portfolio project while its public repository is being prepared. Its project visual is an illustrative concept, not a screenshot of a deployed app. The SilverHands and Credit Card Fraud Detection visuals are also portfolio mockups; NeuroLimb uses a screenshot from the running simulator.
