# Project screenshots

Drop real screenshots here, then point to them in `src/data/projects.ts`:

```ts
screenshots: [
  '/screenshots/neurolimb-1.png',   // top-left
  '/screenshots/neurolimb-2.png',   // bottom-left
  '/screenshots/neurolimb-3.png',   // tall right
],
```

Until a project has `screenshots`, the card shows an original conceptual illustration
(clearly captioned as an illustration, not a screenshot).

Real repository / demo links go in the same file via `github` and `demo`.
A button only appears when its URL exists.
